# CalmClip demo website

A responsive static product website built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` directly, or run a local server from this folder:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included

- Responsive desktop and mobile layouts
- Exact approved device and clip image references supplied in the conversation
- Interactive low-volume white-noise website sample
- Product features, attachment steps, specification targets, gallery, FAQ, and launch-list demo form
- No external libraries, fonts, APIs, or network dependencies
